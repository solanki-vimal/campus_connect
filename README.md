# campus_connect

CampusConnect is a Flutter-based college utility mobile application for students, faculty, club coordinators, and administration. It is designed as a centralized college communication and utility app that uses decentralized content management — different authorized users manage the content relevant to their department or club instead of making one central administrator responsible for everything.
